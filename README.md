
## Local Preview

Open `index.html` directly in a browser or serve the folder:

```sh
python3 -m http.server 8000
```

## Updating The Directory

Add a new project by inserting another `.project` link in the grid with the GitHub Pages URL, display name, short description, and an accent color.
